Here is a python Script that unzips the zip file while tranferring it to your computer from other device without copying it to C drive like temp folder.

useful if you have no space in C drive and want the extracted content in your secondary drive.

By just using ftp server apps like Cx File Explorer setting a local ftp server via usb tethering or wifi/hotspot.

Just enter the ip-port-username-password-destination_folder and file you are copying witht its path.
The script will extract the content of zip file and tranfer it to yur pc without making any copy of either zip or extracted files.
